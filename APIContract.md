# API and Protocol Contract Specification

## 1. RESTful API Specification

Base URL: `/api/v1`

All requests and responses use the `application/json` Content-Type header unless otherwise specified.

---

### 1.1 Create Room

Creates a new streaming room and returns the 12-character room identifier alongside host authorization credentials.

- Endpoint: `POST /api/v1/rooms`
- Authentication: None

Request Payload:

```json
{
  "host_client_id": "c7f93a10-8b43-4e6f-9984-7a1b4129b0a1",
  "host_display_name": "Sarah Connor",
  "access_mode": "pin",
  "pin": "482910",
  "control_policy": "host_only",
  "stream_url": "https://cdn.example.com/live/stream.m3u8",
  "diagnostics_enabled": true
}
```

Field Specifications:
- `host_client_id` (string, required): Deterministic persistent client UUID generated by client fingerprint wrapper.
- `host_display_name` (string, required): Display name chosen by host (1 to 32 characters).
- `access_mode` (string, required): One of `"public"`, `"pin"`, `"approval"`.
- `pin` (string, optional): Required if `access_mode` is `"pin"`. 4 to 16 alphanumeric characters.
- `control_policy` (string, required): One of `"host_only"`, `"collaborative"`.
- `stream_url` (string, optional): Initial direct media URL (HLS `.m3u8`, DASH `.mpd`, MP4, or WebM).
- `diagnostics_enabled` (boolean, required): Whether stream and network diagnostics are enabled for participants.

Response Payload (HTTP 201 Created):

```json
{
  "room_id": "Ab9xK3mP8qRt",
  "room_url": "https://streamroom.app/watch/Ab9xK3mP8qRt",
  "host_token": "hst_9f02b1c4e8a1d7f6e3c5b8a0",
  "session_token": "ses_4b8a2e1d7c9f0b3e6a1c8d5e",
  "settings": {
    "access_mode": "pin",
    "control_policy": "host_only",
    "stream_url": "https://cdn.example.com/live/stream.m3u8",
    "diagnostics_enabled": true
  },
  "created_at": 1727820000.0
}
```

### 1.2 Query Room Status

Queries the public accessibility state of a room prior to entering.

- Endpoint: `GET /api/v1/rooms/{room_id}`
- Authentication: None

Response Payload (HTTP 200 OK):

```json
{
  "room_id": "Ab9xK3mP8qRt",
  "exists": true,
  "access_mode": "pin",
  "requires_pin": true,
  "requires_approval": false,
  "stream_configured": true,
  "active_participants_count": 5
}
```

Error Response (HTTP 404 Not Found):

```json
{
  "error": "ROOM_NOT_FOUND",
  "message": "The specified 12-character room does not exist or has expired."
}
```

---

### 1.3 Submit Join Request (Knock / PIN Challenge)

Authenticates a visitor requesting entry into a room.

- Endpoint: `POST /api/v1/rooms/{room_id}/join-request`
- Authentication: None

Request Payload:

```json
{
  "client_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012",
  "display_name": "Alex Murphy",
  "pin": "482910"
}
```

Response Payload - Approved or Public Access (HTTP 200 OK):

```json
{
  "status": "approved",
  "session_token": "ses_8a1b2c3d4e5f60718293a4b5",
  "room_id": "Ab9xK3mP8qRt"
}
```

Response Payload - Pending Host Approval Queue (HTTP 202 Accepted):

```json
{
  "status": "pending_approval",
  "request_id": "knk_3b8a1c9e7f4d2a0",
  "message": "Waiting for host to admit you into the room."
}
```

Error Response - Invalid PIN (HTTP 401 Unauthorized):

```json
{
  "error": "INVALID_PIN",
  "message": "The provided PIN code is incorrect."
}
```

---

### 1.4 Check Approval Status

Used by visitors in the knocking queue if polling is needed as a WebSocket fallback.

- Endpoint: `GET /api/v1/rooms/{room_id}/knock-status/{client_id}`
- Authentication: None

Response Payload (HTTP 200 OK):

```json
{
  "client_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012",
  "status": "approved",
  "session_token": "ses_8a1b2c3d4e5f60718293a4b5"
}
```

Status can be `"pending"`, `"approved"`, or `"rejected"`.

---

### 1.5 Update Room Settings (Host Only)

Modifies room parameters dynamically during playback.

- Endpoint: `PATCH /api/v1/rooms/{room_id}/settings`
- Authentication: Header `Authorization: Bearer <host_token>`

Request Payload:

```json
{
  "control_policy": "collaborative",
  "stream_url": "https://cdn.example.com/live/backup_stream.m3u8",
  "diagnostics_enabled": true,
  "access_mode": "public"
}
```

Response Payload (HTTP 200 OK):

```json
{
  "status": "updated",
  "settings": {
    "access_mode": "public",
    "control_policy": "collaborative",
    "stream_url": "https://cdn.example.com/live/backup_stream.m3u8",
    "diagnostics_enabled": true
  }
}
```

---

### 1.6 Website Co-Browsing Proxy

Fetches external web pages, strips frame-busting security headers (`X-Frame-Options`, `Content-Security-Policy`), rewrites relative links, and injects the synchronization agent bridge script.

- Endpoint: `GET /api/v1/proxy?url={encoded_target_url}`
- Authentication: None
- Response: Transformed HTML page with injected synchronization agent bridge script (`Content-Type: text/html`)

---

## 2. WebSocket Protocol Specification

Connection URL:
`wss://streamroom.app/ws/rooms/{room_id}?token={session_token}&client_id={client_id}`

### 2.1 Standard Frame Format

All messages transmitted across the WebSocket channel use a standard JSON envelope:

```json
{
  "event": "event_name",
  "payload": {},
  "timestamp": 1727820000.123
}
```

---

### 2.2 Event Catalog

#### 2.2.1 Event: `room:knock` (Server to Host)
Dispatched to the host's active connection when a new user enters the approval queue.

Payload:
```json
{
  "client_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012",
  "display_name": "Alex Murphy",
  "requested_at": 1727820005.412
}
```

#### 2.2.2 Event: `room:knock_decision` (Host to Server)
Sent by the host to accept or deny a user waiting in the queue.

Payload:
```json
{
  "client_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012",
  "decision": "admit"
}
```
Field `decision` must be `"admit"` or `"reject"`.

#### 2.2.3 Event: `room:joined` (Server to Client)
Sent to a newly connected client immediately upon connection authorization. Contains initial synchronized state.

Payload:
```json
{
  "room_id": "Ab9xK3mP8qRt",
  "is_host": false,
  "settings": {
    "control_policy": "host_only",
    "stream_url": "https://cdn.example.com/live/stream.m3u8",
    "diagnostics_enabled": true
  },
  "playback_state": {
    "status": "playing",
    "reference_position": 142.35,
    "reference_timestamp": 1727820010.0,
    "playback_rate": 1.0,
    "active_subtitle_track": "eng",
    "active_audio_track": "stereo_default"
  },
  "participants": [
    {
      "client_id": "c7f93a10-8b43-4e6f-9984-7a1b4129b0a1",
      "display_name": "Sarah Connor",
      "is_host": true,
      "is_voice_active": true
    },
    {
      "client_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012",
      "display_name": "Alex Murphy",
      "is_host": false,
      "is_voice_active": false
    }
  ]
}
```

#### 2.2.4 Event: `room:user_joined` (Server to All)
Broadcast when a new participant enters the room.

Payload:
```json
{
  "client_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012",
  "display_name": "Alex Murphy",
  "is_host": false
}
```

#### 2.2.5 Event: `room:user_left` (Server to All)
Broadcast when a participant disconnects.

Payload:
```json
{
  "client_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012"
}
```

#### 2.2.6 Event: `sync:play` (Client to Server & Server to All)
Sent to begin or resume synchronized playback.

Payload:
```json
{
  "position": 142.35,
  "playback_rate": 1.0
}
```

#### 2.2.7 Event: `sync:pause` (Client to Server & Server to All)
Sent to pause synchronized playback.

Payload:
```json
{
  "position": 142.35
}
```

#### 2.2.8 Event: `sync:seek` (Client to Server & Server to All)
Sent to jump playhead to a new timestamp.

Payload:
```json
{
  "target_position": 350.00
}
```

#### 2.2.9 Event: `sync:track_change` (Client to Server & Server to All)
Sent to synchronize subtitle or audio track selections.

Payload:
```json
{
  "track_type": "subtitle",
  "track_id": "spa_latam",
  "language": "es"
}
```
Field `track_type` is `"subtitle"` or `"audio"`.

#### 2.2.10 Event: `sync:url_change` (Host to Server & Server to All)
Dispatched when the host inputs a new external video or stream URL.

Payload:
```json
{
  "stream_url": "https://media.example.org/event/feed.mpd"
}
```

#### 2.2.11 Event: `sync:media_mode_change` (Host to Server & Server to All)
Dispatched when the host toggles between Video Player and Co-browsing Web Page.

Payload:
```json
{
  "media_mode": "web_page",
  "url": "https://en.wikipedia.org/wiki/Streaming_media"
}
```

#### 2.2.12 Event: `sync:web_navigate` (Host/Collaborator to Server & Server to All)
Dispatched when the host navigates to a new page or clicks an external link.

Payload:
```json
{
  "url": "https://en.wikipedia.org/wiki/Real-Time_Streaming_Protocol"
}
```

#### 2.2.13 Event: `sync:web_scroll` (Host/Collaborator to Server & Server to All)
Dispatched when the host scrolls the embedded webpage.

Payload:
```json
{
  "topPct": 0.428,
  "leftPct": 0.0
}
```

#### 2.2.14 Event: `sync:web_click` (Host/Collaborator to Server & Server to All)
Dispatched when an element or coordinate is clicked.

Payload:
```json
{
  "xPct": 0.652,
  "yPct": 0.310
}
```

#### 2.2.15 Event: `sync:web_cursor` (Host to Server & Server to All)
Dispatched at high frequency to broadcast host cursor pointer position.

Payload:
```json
{
  "client_id": "c7f93a10-8b43-4e6f-9984-7a1b4129b0a1",
  "xPct": 0.512,
  "yPct": 0.284
}
```


#### 2.2.11 Event: `chat:message` (Bi-directional)
Dispatched when a user sends a text chat message.

Payload:
```json
{
  "id": "msg_01h8a9bcdef0123456789abc",
  "sender_client_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012",
  "sender_name": "Alex Murphy",
  "is_host": false,
  "content": "Audio is clear on my end.",
  "sent_at": 1727820015.892
}
```

#### 2.2.12 Event: `time:ping` and `time:pong` (Bi-directional)
Client sends `time:ping` with local client timestamp `t0`. Server responds with `time:pong` containing server monotonic timestamp `t_server` and echoing `t0`. Used to compute clock offset and RTT.

Payload `time:ping`:
```json
{
  "t0": 1727820018.100
}
```

Payload `time:pong`:
```json
{
  "t0": 1727820018.100,
  "t_server": 1727820018.115
}
```

#### 2.2.13 WebRTC Voice Signaling Events
Used to negotiate peer-to-peer voice connections.

`webrtc:join_voice` (Client to Server):
```json
{}
```

`webrtc:active_voice_peers` (Server to Client):
```json
{
  "peers": ["c7f93a10-8b43-4e6f-9984-7a1b4129b0a1"]
}
```

`webrtc:offer` (Client to Server / Server to Peer):
```json
{
  "source_peer_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012",
  "target_peer_id": "c7f93a10-8b43-4e6f-9984-7a1b4129b0a1",
  "sdp": "v=0\r\no=- 4208034 2 IN IP4 127.0.0.1..."
}
```

`webrtc:answer` (Client to Server / Server to Peer):
```json
{
  "source_peer_id": "c7f93a10-8b43-4e6f-9984-7a1b4129b0a1",
  "target_peer_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012",
  "sdp": "v=0\r\no=- 9104821 2 IN IP4 127.0.0.1..."
}
```

`webrtc:ice_candidate` (Client to Server / Server to Peer):
```json
{
  "source_peer_id": "e8b21a4f-5d3c-4b71-91a0-3e4b7c89f012",
  "target_peer_id": "c7f93a10-8b43-4e6f-9984-7a1b4129b0a1",
  "candidate": {
    "candidate": "candidate:842163049 1 udp 1677729535 192.168.1.100 54123 typ host...",
    "sdpMid": "0",
    "sdpMLineIndex": 0
  }
}
```
